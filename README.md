# Topics covered

I wrote 2 article series about this topic: 

- [Serverless applications with Java and Aurora DSQL](https://dev.to/vkazulkin/series/34625)
- [Serverless applications on AWS with Lambda using Java 25, API Gateway and Aurora DSQL](https://vkazulkin.com/series/serverless_applications_on_aws_with_lambda_using_java_25_api_gateway_and_aurora_dsql/) on how to develop, run, and optimize Serverless applications using managed Java 25 on Lambda, API Gateway and Aurora DSQL relational database. Examples include usage of Hikari pool with plain JDBC or Hibernate framework. Performance optimization approaches include usage of Lambda SnapStart with priming techniques and GraalVM Native Image
